🤖 Remote Mower — Test Vehicle BOM

Rev 1.0  ·  2026-03-17  ·  V3: RC Control (Flysky FS-i6X + FS-iA6B iBUS)  ·  3-Wheel Differential Drive

Architecture — Arduino UNO Q Dual-Brain

🐧 Linux Brain
Qualcomm Dragonwing QRB2210 · quad-core 2.0 GHz
  • Debian OS + Python
  • WebSocket server + web control UI
  • WiFi 5 · Bluetooth 5.1
  • AI / computer vision (future)
⚡ Real-Time Brain
STM32U585 MCU · Arduino sketches
  • Motor PWM → Cytron MDD10A
  • Safety watchdog (heartbeat monitor)
  • E-stop logic
  • If heartbeat missed ×3 → motors off
FS-iA6B Receiver
  ├── VCC ←── Buck 5V rail
  ├── GND ←── Common GND
  └── iBUS ──→ STM32 Serial1 RX (D0)   [single wire · all 6 channels · 115200 baud]

Battery (12V)
  ├── [E-Stop NC] ──→ [Main Switch] ──→ Cytron MDD10A ──→ Motor L (M1)
  │                                                              └──→ Motor R (M2)
  └── [Buck 12→5V] ──→ UNO Q (5V USB-C) + FS-iA6B VCC
                              └── STM32 Serial1 RX ←── FS-iA6B iBUS (CH3=throttle · CH4=rudder)
                              └── STM32 PWM GPIO ──→ MDD10A DIR1/PWM1/DIR2/PWM2
                              └── Linux side ──→ (idle in Phase 1)
